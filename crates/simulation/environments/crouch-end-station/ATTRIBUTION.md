# Crouch End Station

[Crouch End Station](https://sketchfab.com/3d-models/crouch-end-station-d2651a5550f34d80b0dba6e971f3a1ae)
by [artfletch](https://sketchfab.com/artfletch).
Licensed under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).

Photogrammetry captured in May 2022 using 2,821 photographs, Sony a7R III,
processed in RealityCapture. The public model API reports 1,907,390 faces and
956,731 vertices. These counts describe the published model, not a performance
measurement or a verified physical scale.

The installed glTF download was obtained through Sketchfab's authorized Download
API. The original archive SHA-256 is
`c02427ac0958fb9fe83665964547ac1ddf0f4639d48758d8bc3f83b08129b07e`.
Its geometry contains 1,907,352 triangles (the public API's published count
above differs slightly).

Modifications: texture-aware mesh simplification to 347,393 triangles, atlas
resizing from 8192 to 2048 px, JPEG re-encoding at quality 85, and packaging as
one unlit GLB. The photographic lighting is retained. All targets use this same
asset. The environment manifest records output SHA-256, placement and spawn.
Source units are treated as meters; scale has not been surveyed. The capture's
missing geometry and incomplete coverage remain visible.
